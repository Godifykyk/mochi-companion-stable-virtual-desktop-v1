# Changelog

## 1.0.0 — 2026-10-03

- Isolated stable source bundle.
- Portable GTK3/layer-shell adapter with Hyprland, Niri, Sway, KWin, and X11 window-metadata backends.
- Native Noctalia, KDE Plasma 6, and GNOME Shell 45+ adapters.
- 120 original anime-inspired modes.
- Fixed white/blue eye palette on black.
- User-local installer, uninstaller, autostart file, distro packaging starters, and compatibility documentation.
- Workspace-correct X11/Niri/Sway smart-hide with non-blocking compositor probes.
- Transactional native installation, ownership-safe autostart handling, and clean upgrades.
- Plasma context-menu preservation and complete desktop-entry packaging.
- Native adapter catalogs no longer contain dangling asset references.
