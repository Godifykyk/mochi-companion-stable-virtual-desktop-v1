# Animation source notes

No third-party character artwork or GIF was copied into Mochi Eyes.

Research references used for behavior and format ideas:

- `sachinthra/robo_eyes` — MIT-licensed eye animation engine; used only as behavioral inspiration for blinking, idle movement, and expression categories.
- `pulkitpriyam/MyDeskRobo` — MIT-licensed desktop companion project; its demo GIF was reviewed as a format reference but was not copied.
- `xiaolai/espresso` — Mochi-style community engine whose repository states that code is MIT but character assets have separate restrictions; none of its character assets were imported.
- `huykhoong/esp32_dasai_mochi_clone_and_how_to` — useful ESP32/Mochi implementation reference, but no clear repository license was found; no files were imported.

All GIFs under `mochi-eyes/assets/gifs/` are generated locally by `generate_anime_pack.py` from original geometric eye shapes. The 120 mode names and sequences are original generic anime-inspired storytelling beats and do not reproduce named characters or scenes.
