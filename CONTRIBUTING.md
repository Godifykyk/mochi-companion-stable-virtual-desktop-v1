# Contributing

1. Open an issue describing the desktop, compositor, distribution, session type, and adapter.
2. Keep the white/blue/black palette invariant.
3. Add tests before implementation changes.
4. Run the isolated release test suite and portable smoke test.
5. Do not add copyrighted anime characters, frames, logos, or extracted GIFs.
6. Update `docs/COMPATIBILITY.md` only with reproducible runtime evidence.

Pull requests should explain resource impact and privacy impact.
